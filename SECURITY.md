# Security Policy

## Reporting a Vulnerability

We value the security of Anuvadini. If you discover a security vulnerability, please report it responsibly by sending an email to:

**js8160303@gmail.com**

Please include as much detail as possible to help us reproduce and fix the issue. We will respond as quickly as possible.

### Our Commitment
- We will acknowledge receipt of your report promptly.
- We will provide an estimated timeframe for addressing the vulnerability.
- We will notify you once the vulnerability has been patched.

Thank you for helping keep Anuvadini secure!
